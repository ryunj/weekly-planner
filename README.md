# 주간 체크리스트 (weekly-planner)

주차별 업무 체크리스트. 카테고리(광고 / EP / 루틴 / 신규 / 기타) × 요일(월~일) 격자에
할 일을 적고 체크하는 1인용 정적 웹앱입니다.

**열기 →** https://ryunj.github.io/weekly-planner/

## 기능

| 기능 | 설명 |
|---|---|
| 주차 이동 | `‹` `›` 또는 `←` `→`, `오늘` 버튼 · ISO 주차(2026-W45) 표기 |
| 할 일 | 셀에 마우스를 올리면 `+ 추가`. Enter로 연속 입력, Esc로 종료 |
| 수정 / 삭제 | 텍스트 클릭 → 바로 수정 · `✕` 삭제 |
| 중요 표시 | `☆` 토글 (굵게 표시) |
| 매주 반복 | `↻` 토글 → 등록한 다음 주부터 자동 생성. 체크 상태는 주차별로 따로 |
| 이동 | 할 일을 드래그해서 다른 요일·카테고리로 |
| 지난주 복사 | 지난주 항목(반복 제외)을 이번 주에 체크 해제 상태로 복사 |
| 진행률 | 전체 / 카테고리별 완료율 |
| 주간 메모 | 전주 리뷰·금주 계획 기록 (주차별 저장) |
| 카테고리 관리 | ⚙ 에서 이름·색·순서 변경, 추가/삭제 |
| 백업 | ⚙ 에서 JSON 내보내기 / 불러오기 |
| 기타 | 다크모드(`D`), 인쇄(`P`) |

## 데이터

- 모든 데이터는 **브라우저 localStorage** 에만 저장됩니다. 서버로 전송되지 않습니다.
- 따라서 **브라우저·기기가 바뀌면 데이터는 따라오지 않습니다.**
  다른 기기에서 쓰려면 ⚙ → `백업 내보내기` 한 JSON을 새 기기에서 `백업 불러오기` 하세요.
- 브라우저 데이터 삭제(쿠키·사이트 데이터 지우기) 시 함께 지워지므로 가끔 백업을 권장합니다.

## 단축키

`←` `→` 주 이동 · `T` 오늘 · `D` 다크모드 · `P` 인쇄

## 구조

`index.html` 한 파일에 HTML·CSS·JS가 모두 들어 있습니다. 빌드 과정 없이 GitHub Pages로 바로 서비스됩니다.
수정 후 커밋·푸시하면 1~2분 내 반영됩니다.
