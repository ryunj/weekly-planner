# 주간 체크리스트 (weekly-planner)

주차별 업무 체크리스트. 카테고리(광고 / EP / 루틴 / 신규 / 기타) × 요일(월~일) 격자에
할 일을 적고 체크하는 1인용 정적 웹앱입니다.

**열기 →** https://ryunj.github.io/weekly-planner/

## 기능

| 기능 | 설명 |
|---|---|
| 주차 이동 | `‹` `›` 또는 `←` `→`, `오늘` 버튼 · ISO 주차(2026-W45) 표기 |
| 할 일 | 셀에 마우스를 올리면 `+ 추가`. Enter로 연속 입력, Esc로 종료 |
| 수정 / 삭제 | 텍스트 클릭 → 바로 수정 · `✕` 삭제 |
| 중요 표시 | `☆` 토글 (굵게 표시) |
| 매주 반복 | `↻` 토글 → 등록한 다음 주부터 자동 생성. 체크 상태는 주차별로 따로 |
| 이동 | 할 일을 드래그해서 다른 요일·카테고리로 |
| 지난주 복사 | 지난주 항목(반복 제외)을 이번 주에 체크 해제 상태로 복사 |
| 진행률 | 전체 / 카테고리별 완료율 |
| 주간 메모 | 전주 리뷰·금주 계획 기록 (주차별 저장) |
| 카테고리 관리 | ⚙ 에서 이름·색·순서 변경, 추가/삭제 |
| 백업 | ⚙ 에서 JSON 내보내기 / 불러오기 |
| 기타 | 다크모드(`D`), 인쇄(`P`) |

## 앱으로 설치 (PWA)

주소를 연 뒤 설치하면 독립 창 + 작업표시줄 아이콘 + **오프라인 사용**이 됩니다.

- **Windows Chrome / Edge** — 주소창 오른쪽 설치 아이콘(⊕ 또는 모니터 모양), 또는 화면 우측 상단 `⬇ 앱 설치` 버튼
- **Android Chrome** — 메뉴 → `앱 설치`
- **iPhone Safari** — 공유 → `홈 화면에 추가` (iOS는 이 방법만 가능)

설치해도 같은 브라우저 프로필의 저장소를 그대로 쓰므로, 탭에서 쓰던 내용이 그대로 보입니다.
비행기/지하철 등 네트워크가 없을 때도 열리며, 입력은 정상 저장되고 상단에 `오프라인` 배지가 표시됩니다.

## 데이터

- 모든 데이터는 **브라우저 localStorage** 에만 저장됩니다. 서버로 전송되지 않습니다.
- 따라서 **브라우저·기기가 바뀌면 데이터는 따라오지 않습니다.**
  다른 기기에서 쓰려면 ⚙ → `백업 내보내기` 한 JSON을 새 기기에서 `백업 불러오기` 하세요.
- 브라우저 데이터 삭제(쿠키·사이트 데이터 지우기) 시 함께 지워지므로 가끔 백업을 권장합니다.
- ⚙ 를 열면 저장 공간을 **영구 보관**으로 요청하고(브라우저가 공간 부족 시 자동 삭제하는 것을 막음),
  현재 보관 방식·사용량·실행 모드를 보여줍니다.

## 단축키

`←` `→` 주 이동 · `T` 오늘 · `D` 다크모드 · `P` 인쇄

## 구조

빌드 과정 없이 GitHub Pages로 바로 서비스됩니다. 수정 후 커밋·푸시하면 1~2분 내 반영됩니다.

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (HTML + CSS + JS) |
| `manifest.webmanifest` | 앱 이름·아이콘·실행 방식 (설치용) |
| `sw.js` | 서비스워커 — 앱 셸 캐시, 오프라인 지원 |
| `icon-*.png`, `apple-touch-icon.png` | 앱 아이콘 |

`sw.js`는 페이지를 **네트워크 우선**으로 가져오므로 푸시한 수정이 바로 반영되고,
네트워크가 없을 때만 캐시로 대체됩니다. 아이콘·매니페스트를 교체했다면 `sw.js`의 `CACHE` 값을
`weekly-planner-v2` 처럼 올려야 기존 캐시가 비워집니다.
